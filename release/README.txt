PROTOTYPE и PROTOTYPE 2 для Nintendo Switch — 1.0.0
Бесплатно. Не для продажи. t.me/fspores

Порты версий для Xbox 360, сделанные статической рекомпиляцией (ReXGlue): код игры переведён
в нативный код ARM64 Switch, графика рисуется через Vulkan (NVK/Mesa), без эмуляции.
Игровых файлов в раздаче НЕТ — нужна своя копия игры для Xbox 360.

=====================================================================
ЧТО НУЖНО
=====================================================================
- Nintendo Switch с Atmosphère 1.8.0+ и sigpatches (для установки NSP).
- DBI (или другой установщик NSP).
- Место на SD: Prototype ~7 ГБ, Prototype 2 ~8 ГБ. FAT32 подходит.
- Своя копия игр для Xbox 360 (образ ISO или распакованная папка с default.xex).

=====================================================================
УСТАНОВКА
=====================================================================
1. Скопируйте папку switch из раздачи в корень SD-карты. Получится:
     sdmc:/switch/prototype-nx/prototype.nro
     sdmc:/switch/prototype-nx/prototype.toml
     sdmc:/switch/prototype2-nx/prototype2.nro
     sdmc:/switch/prototype2-nx/prototype2.toml

2. Положите файлы своей игры:
     Prototype   -> sdmc:/switch/prototype-nx/game/      (внутри должен лежать default.xex)
     Prototype 2 -> sdmc:/switch/prototype2-nx/game_root/ (внутри должен лежать default.xex)
   Если у вас образ ISO, распакуйте его, например, extract-xiso:
     extract-xiso -x "Prototype.iso" -d game
   Папка $SystemUpdate не нужна.

3. Установите через DBI оба NSP из папки nsp:
     Prototype [0150524F54310000][v0].nsp
     Prototype 2 [0150524F54320000][v0].nsp
   Они ставят иконки на HOME и запускают игры с полной памятью приложения.

4. Запускайте с иконки на HOME.
   Без NSP: удерживайте R при запуске любой установленной игры, в Homebrew-меню выберите
   Prototype / Prototype 2. Через Альбом НЕ запускайте — не хватит памяти.

=====================================================================
НАСТРОЙКИ
=====================================================================
Файлы prototype.toml / prototype2.toml рядом с NRO. После изменения полностью закройте игру.

Prototype 2, графика (наш пресет, у автора порта было меньше):
  p2_render_width / p2_render_height  внутреннее разрешение, 960x544 + FSR (было 640x352)
  p2_native_texture_lod_bias          резкость текстур, 0.5 (было 1.0)
  p2_native_max_anisotropy            анизотропия, 2 (было 1)
  p2_geo_lod_bias_scale               детализация моделей, 2.0 (было 4.0; меньше = лучше)
  p2_shadow_range_scale               дальность теней, 0.5 (было 0.3)
  p2_ped_max_scale / p2_vehicle_max_scale  пешеходы и машины, 0.3 / 0.15 — сильнее всего грузят
                                      процессор, поднимать не советуем
  user_language = 12 — русский, 1 — английский

=====================================================================
ПРОИЗВОДИТЕЛЬНОСТЬ И ЧАСТОТЫ
=====================================================================
Проверено на Switch OLED (Mariko) с разгоном CPU 1785 / GPU 768–1152 / RAM 2333 МГц:
  Prototype   — ролики и меню 30–60 FPS, в игре 11–25 FPS
  Prototype 2 — в городе 25–30 FPS
На штатных частотах FPS ниже.

Prototype 2 использует все 4 ядра и греет консоль заметно сильнее первой части.
Если у вас Horizon OC / sys-clk, задайте для Prototype 2 (0150524F54320000) отдельный профиль.
На старой ревизии (Erista) высокий разгон не используйте.

=====================================================================
ИЗВЕСТНЫЕ ПРОБЛЕМЫ
=====================================================================
- Подтормаживания при первой загрузке новых мест (создаётся кэш шейдеров; потом плавнее).
- Prototype: «тяжёлые» сцены в открытом мире могут опускаться ниже 15 FPS.
- Полное прохождение обеих игр не проверялось. Пишите о проблемах: t.me/fspores

=====================================================================
ЧТО ИСПРАВЛЕНО В НАШЕЙ СБОРКЕ
=====================================================================
Prototype (порт fungalspores):
  - взаимные блокировки потоков игры (зависания в роликах, переходах и после паузы);
  - «повреждённые» сохранения (игра записывает в сейв размер файла, SDK отдавал старый);
  - подпись консоли для сохранений;
  - нативный рендер вместо эмуляции видеочипа: звук, 30–60 FPS в меню и роликах.
Prototype 2 (порт penettrator, собран нами из его исходников):
  - те же исправления SDK (сохранения, подпись, блокировки);
  - графика лучше (см. настройки);
  - переход на 4 ядра без вылетов модулей разгона (убран опрос датчиков температуры).
